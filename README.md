# 📱 Mobile Sales Performance Dashboard | Power BI

## 📊 Project Overview

An interactive **Mobile Sales Performance Dashboard** developed using Microsoft Power BI to analyze sales performance across products, brands, cities, customers, payment methods, and time.

## 🎯 Project Objective

The objective of this project is to provide a consolidated view of mobile sales performance and make it easier to explore key business metrics and identify sales patterns through interactive visualizations.

## 📌 Key KPIs

- **Total Sales:** 59M
- **Total Quantity:** 1K
- **Transactions:** 291
- **Average:** 41.0K

## 🔍 Dashboard Features

- City-wise sales analysis using a map
- Daily quantity and sales trend analysis
- Customer rating distribution
- Transaction analysis by payment method
- Brand-wise sales, quantity, and transaction comparison
- Mobile model sales analysis
- Interactive filters for Month, Mobile Model, Customer Name, Payment Method, and Brand

## 🛠️ Tools & Technologies

**Microsoft Power BI | Data Visualization | Interactive Dashboarding**

## 💼 Business Value

The dashboard brings multiple sales dimensions into a single interactive reporting view, allowing users to monitor KPIs, compare brands and mobile models, analyze customer and payment patterns, and explore sales trends efficiently.
